给人用的交互终端，做法接近 FinalShell：选主机，开一个或多个标签。这里输入的命令不走允许 / 拒绝 / 确认，只记审计（来源 ui）。命令行和「执行」页仍然拦截。连接复用本机会话，空闲 5 分钟，最长 60 分钟。这个版本没有端口转发。
