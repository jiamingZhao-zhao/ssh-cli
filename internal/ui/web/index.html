一台主机只能属于一个分组，环境从分组继承。分组上的命名策略和允许 / 拒绝 / 确认会参与该组主机的规则合并。有主机时不能删除，和 group remove 一样。

添加分组

空的允许列表会让这一层把命令都交空。名称创建后不能改。分组没有标签。

分组环境主机全组标签

标签只写在主机上，用来配合 ssh-cli -t 选择主机，不表示权限。分组没有 tags 字段。把标签加到某个分组，实际是写到该分组里的每一台主机上。

添加环境

maxMode 是天花板。defaultPolicy 是环境这一层引用的命名策略。环境本身没有行内 allow / deny。dev、test、preprod、prod 是内置环境，不能改也不能删。可以另加自定义环境。

名称来源模式允许拒绝确认

添加命名策略

覆盖内置 readonly / standard / admin 时，会先复制内置定义再写入 hosts.yaml，能力开关会留下来。删掉这条覆盖会恢复内置。仍被引用的自定义策略不能删除。

规则写在命名策略上，或挂到环境、分组、主机。某一层不写允许列表，这一层就是全集；写成空列表则会把这一层交空。拒绝和确认在各层取并集。内置硬拒绝（删除根目录、mkfs、把 dd 或重定向写到磁盘、修改根目录属主、fork bomb）不能在这里关掉。这个页面不配置 relay、elevate 或策略 HMAC。

标记类型指纹

这是本机 known_hosts 里的 TOFU 记录。删除一条后，下次连接会记下看到的第一把钥匙；已经记下的钥匙如果变了，仍然会拒绝。
