# 0.7.21：文件区高度、传输队列对齐、主机三行与网络图

本版只改本机工作区的排布。源码里的 `Version` 仍是 `dev`，发布号由 tag 经 ldflags 注入。没有新的运行时依赖；进程表下面的速率图用的是页面里已有的 Chart.js。目录选择仍是 JSON POST，进程表仍是内存占用最高的 5 条。

## 文件和历史

- 右侧「文件 / 历史」默认高度约为视口的三分之一（`33.333vh`），不再固定 280px。
- 上下拖动分隔条可以改高度。松手后记在本机偏好里，下次打开仍用这次的高度。最小 160px，不超过视口高度减去 180px。大屏上拖动从当前高度接着走，不会跳回旧的固定上限。

## 传输队列

- 「传输队列」标题与右侧文件栏同一行、同一高度对齐。
- 下载目录单独占标题下面一行。点路径仍选择目录；选过之后旁边仍可点「默认」恢复。
- 「清除已完成」改到标题行右侧，只在有已经结束的记录时出现。
- 队列是空的时候，虚线框写着「拖到这里下载」和「点击选择下载目录」。点它、或在框上按 Enter / 空格，仍打开目录选择。

## 主机信息

概况标题改成三行。还没连上时，这三行也留在概况顶部：

- 第一行是「主机名称」，显示远端主机名。没有主机名时是「—」。不再写成「主机名/登录用户」。
- 第二行是「主机别名」，显示配置里的别名。
- 第三行是状态和 IP。状态是纯文字（在线、连接中、已断开、已到期、未连接），前面有一个小圆点。点 IP 复制地址。

## 网络

- 进程表下方是上传、下载速率小图，用 Chart.js 画柱。当前速率写在图上方（↑ 上传、↓ 下载），单位是 B/s、KB/s 这一类。
- 每个主机单独记最近 24 次采样，多出来的丢掉。换主机或离开工作区时清空。
- 速率来自概况里的网卡合计，不含回环网卡 `lo`。读不到时（未连接、概况失败，或接口注明网络不可用）显示「—」，图上留空；真正的 0 仍显示 `0 B/s`。
