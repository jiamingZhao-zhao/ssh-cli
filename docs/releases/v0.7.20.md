# 0.7.20：进程 Top 5、固定左栏、行点击详情

本版只改本机工作区概况。源码里的 `Version` 仍是 `dev`，发布号由 tag 经 ldflags 注入。没有新的运行时依赖。目录选择仍是 JSON POST，终端标签仍和主机选择同一行，磁盘仍只显示去掉尾部 `/` 的根分区。

## 概况

- 进程表和 `metrics` 都只保留内存占用最高的 5 条。没连上、或还没有进程数据时，表头仍在，下面固定 5 行空位，左栏不因此收起来。
- CPU、内存、交换、磁盘这四条进度条始终在表上面。没有数据时数值是「—」，进度条是空的。
- 左栏始终占满终端一侧的高度。空的传输区用虚线框填在中间，「传输队列」和保存目录钉在左下角。
- 保存目录始终显示在「传输队列」旁边。点它仍走 `POST /api/download-dir` 选择目录。
- 已经下载完的条目可以点开，本机用文件管理器打开该文件所在的目录（`POST /api/download-dir/reveal`）。
- 去掉每行右侧的「详情」。点有数据的那一行，或在该行上按 Enter / 空格，打开原来的详情。
