# 0.7.19：目录选择、传输队列、进程和磁盘

本版只改本机工作区的六处交互，以及概况进程条数。源码里的 `Version` 仍是 `dev`，发布号由 tag 经 ldflags 注入。没有新的运行时依赖。命令行和页面仍走同一条 SFTP 传输。

## 目录

- 选择下载目录的请求是 `POST /api/download-dir`，请求体为 JSON（`Content-Type: application/json`）。
- 不再因「mutating requests must use JSON」失败。其它变更请求若不是 JSON，仍拒绝。

## 传输队列

- 队列在左侧栏底部，与右侧「文件 / 历史」同一行。
- 没有传输时只显示小字「传输队列」和一个虚线框。点虚线框仍可打开系统目录选择器，也可把远端文件拖进去下载。
- 有记录时才显示保存路径、「清除已完成」和进度。

## 概况

- 进程表和 `metrics` 都只保留内存占用最高的 7 条。页面不再在接口返回之后再截成 5 条。
- 磁盘挂载点去掉末尾的 `/`。页面只显示根分区 `/` 的一条用量：上一行是「磁盘」和已用/全部，下一行是整宽进度条。

## 终端

- 终端标签与主机选择、「打开 / 连接 / 断开」在同一行。
