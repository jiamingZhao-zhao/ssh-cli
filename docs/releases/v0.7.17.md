# 0.7.17：工作区概况、进度和连接状态

本版只调整本机工作区的排布和传输进度。源码里的 `Version` 仍是 `dev`，发布号由 tag 经 ldflags 注入。没有新的运行时依赖。

## 概况

- 磁盘紧挨在交换下面、进程表上面。每一行是挂载点、进度条和 `28% · 10.0 GB / 40.0 GB` 这种已用/全部，挂载点不再单独折到进度条上方。
- 进程表只显示内存占用最高的 5 条，从高到低。命令列只留可执行文件的短名称；完整启动命令在该行的「详情」里。「详情」是这一行的详情，按钮没有边框。

## 传输

- 下载和上传在传输队列里显示百分比、已传/总字节，以及和 CPU、内存、交换相同的进度条。
- 页面在请求里声明要进度时，服务端按块写出已传字节；不声明时仍是原来的一条 JSON。取消仍只关闭这次传输自己的 SSH 连接。

## 终端

- 去掉终端窗格上的「终端」标题。
- 连接状态（主机、环境、地址、已连接，以及空闲和最长剩余）放在终端和文件区之间的分隔条上，上面不再留一份。
- 左侧概况和传输队列与右侧终端和文件区共用同一条水平分隔，左右列边对齐。
