# 0.7.18：工作区对齐、磁盘行和传输队列

本版只调整本机工作区的排布和保存目录的选择方式。源码里的 `Version` 仍是 `dev`，发布号由 tag 经 ldflags 注入。没有新的运行时依赖。命令行和页面仍走同一条 SFTP 传输。

## 概况

- 磁盘和内存、交换使用同一套两行：上一行是「磁盘」和挂载点，右侧是 `28% · 9.3 GB / 35.3 GB` 这种已用/全部；下一行是整宽进度条。挂载点不再插在进度条中间。
- 进程表只留横线。内存、CPU、命令的表头和单元格居中对齐；命令列的短名称在列中央，「详情」仍在右侧可点。
- 进程表贴齐左栏宽度，概况下面不再留一大块空白。传输队列紧接在进程表下面。

## 传输

- 队列标题旁边显示保存目录。点它打开系统的目录选择器，不用手填路径。没选过时仍是默认 Downloads（存在时），否则是 `~/ssh-cli-downloads`。
- 把远端文件拖到下载区，仍由本机进程调用和 `ssh-cli download` 相同的 SFTP，写到所选目录。
- 没有传输时显示空状态，而不是一行「没有传输记录」。
- 「清除已完成」只在有已结束、可以清掉的记录时出现。

## 终端和文件

- 终端标签贴着主机选择和「打开 / 连接 / 断开」那一栏，中间不再留白带。
- 连接状态（主机、环境、地址、已连接，以及空闲和最长剩余）改到「文件 / 历史」标题行右侧，不再单独占终端和文件之间的一条横栏。拖动文件区高度的细分隔还在。
- 还没打开终端时，文件和历史的内容区留白，不再放「还没有打开终端」和「打开终端」按钮。打开终端仍在终端区。
