## 指定 SSH agent 公钥

先在本机通过 `ssh-add -l` 查看公钥指纹，在已有 agent 主机上设置：

```sh
ssh-cli host edit hn-test-105 --agent-key 'SHA256:<完整指纹>'
```

新增主机时搭配 `--agent --agent-key`。网页主机表单勾选 agent 后填写同一指纹。`--agent-key ''` 清除选择，仍保持 agent 认证；切换到密码或私钥认证会清除选择。指纹不是私钥，不转发 agent、不导出私钥，也不回退其他认证方式。未指定时保持原有最多尝试 16 个身份的边界；指定身份时只尝试这一把，允许从较大的 keyring 中选择。

指纹纳入现有策略签名和整条连接路由的身份计算。为空时保持旧的连接指纹和签名兼容；配置读取按请求复用，建立新连接时仍重新检查保存的主机身份。
