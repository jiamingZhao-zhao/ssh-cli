# 0.7.26：文件安全、审计完整性与 Agent 使用体验

本次整合文件安全和产品完成度审查。源码版本仍为 `dev`，发布版本由 tag 注入；本 PR 不创建标签、不发布、不自动合并。

## 文件与异常恢复

- 下载写入同目录随机临时文件，完整复制、同步、关闭后才替换目标。失败保留已有文件；本地目标软链接和非普通文件拒绝替换。Windows 提交沿用现有受保护 DACL 的替换工具。
- 跨机拷贝先写远端随机临时文件，在临时文件上校验 SHA-256（缺少命令时兼容 MD5），通过后再安全替换。已有目标保留原权限，新目标沿用源文件普通权限位；目标和父目录软链接拒绝跟随；保护路径按远端 HOME 和别名展开后复查。取消或 UI 的两分钟预算到期关闭两端专用连接。
- 网页上传直接读取 multipart 已暂存的文件，取消第二次完整本地复制。仍支持大文件；超过 32 MiB 的 multipart 会落到临时盘。服务端最多同时接纳两项上传、下载或跨机拷贝，覆盖多页面调用；超额请求返回明确未开始的结果，不自动排队重放。
- 会话凭据失效时，只有收到服务端在操作分发前标记的拒绝响应，页面才重新建会话并重试一次；普通权限拒绝不重试。
- 传输、单命令、批量命令和文件变更的待核验元信息保存在当前标签的 sessionStorage。刷新后恢复为待核验，不恢复文件内容、命令文本、输出或自动执行。浏览器禁用存储或关闭标签后仍可能丢失；操作结果缓存依然不承诺跨服务重启或过期去重。
- 递归删除先检查范围，超过 10000 项或 64 层拒绝；文件目录仍须依靠服务端权限隔离并发改动。

下载仍沿用同名覆盖语义。目录传输逐文件提交，不保证整棵目录原子性。取消可能发生在最终替换之后；未知结果仍必须核验。断网后远端临时文件清理是尽力而为。

## 审计完整性与保留

```text
ssh-cli audit protect
ssh-cli audit verify --json
ssh-cli audit configure --retention-days 90 --require-writable
```

`protect` 和 `configure` 需要真人在 TTY 输入对应短语。`protect` 将现有 JSONL 原字节作为初始基线，不重写历史内容。每个日文件使用链式 HMAC，签名的 `audit/integrity.json` 锚定文件集合、行数、字节数和链头。校验覆盖修改、重排、截断和文件缺失；重复 `protect` 不会静默重签损坏的基线。启用标记纳入策略 HMAC，检查点缺失会报错。

启用后启动校验全量记录，追加校验当前日文件；UI 长进程仅在文件元数据和可信链头一致时复用验证结果。显式 `verify` 始终读取全量字节。崩溃发生在日志和检查点两次写入之间会导致校验失败；本版不会擅自修复或重新签名，需由人从可信备份核对和恢复。

**边界：本地 HMAC 不是不可篡改存储。能读取主密钥的同账号进程可以伪造；同时回滚日志与旧检查点也无法仅靠本机发现。需要独立可信的检查点备份或远端留存。历史基线签名不证明启用前的记录真实。**

自动保留默认关闭，`retentionDays: 0` 不删除历史。启用后在进程启动时清理完整过期日文件，并记录清理摘要；至少保留 30 天。启用完整性时不重写保留边界日。现有手动清理仍可使用。配置通过现有保存路径更新策略签名。

`requireWritable` 默认关闭；启用后远端操作分发前先持久化准入记录，失败则拒绝新操作。操作开始后出现磁盘故障仍只能告警，无法回滚远端副作用。已存在的交互终端不会在每次按键前同步写日志。

## 认证、破窗与复用

- 主机新增 `--agent` / `auth: agent`，UI 主机表单也可选择。本机 Unix socket 使用 `SSH_AUTH_SOCK`；Windows 未指定时使用 OpenSSH agent 管道。每次签名使用本地 Agent，支持 RSA SHA-2，不转发到远端、不导出私钥、不静默回退到密码。Agent 通信有期限；空 keyring 和超过 16 个身份会明确报错。跳板使用同一认证入口。
- 新增仓库根目录 [SKILL.md](../../SKILL.md)，说明 JSON 结果、退出码、确认拒绝和未知结果的处理。

```text
ssh-cli elevate configure prod --max-ttl 30m
ssh-cli elevate server-alias --ttl 15m --reason "部署修复" -- touch /tmp/deploy-marker
ssh-cli elevate configure prod --disable
```

破窗默认关闭，每次需要真人在 TTY 输入 `elevate:<alias>`，拒绝 `--yes` 和非交互调用。只作用于一台主机的一条命令，将环境隐式只读默认临时提高到 standard；显式 group/host 策略、deny、自定义 readonly 策略及数据外流限制继续生效，不产生共享提权文件、不修改原策略。授权准入必须成功落审计，TTL 最高一小时且受配置上限限制。TTL 限制当前 SSH 操作，不保证杀死远端脱离会话的进程，也不能回滚已经完成的变更。

```text
ssh-cli daemon serve
ssh-cli exec --daemon -H server-alias --json -- df -h
```

常驻复用显式启动、默认关闭。使用本机 AF_UNIX 通道和私有随机 Token，不监听 TCP、不复用网页会话。Windows 需要 AF_UNIX 支持；本地 socket 路径过长或系统不支持时明确失败。每个请求重新加载并验证配置、主机连接指纹和命令策略；策略变化立即用于新请求，连接身份变化淘汰原连接，拨号随请求取消。实际执行记录由服务端写入，客户端结果记录标为 session，避免统计成两次执行。最多 16 台主机、4 个操作并发，沿用空闲/最长寿命清理。

首版仅支持字面量 `exec`，拒绝确认类命令、`--stdin` / `--script` 和其他子命令的 `--daemon`。每路输出最多 64 KiB，截断会告警。没有隐式启动、自动重试、失败回退或缓存写操作结果。需要人工确认的命令和文件传输继续使用直连。服务崩溃可能留下 socket，确认旧进程停止后手动移除报错指定的路径。Token 不应授予不可信进程；同系统账号权限隔离仍是边界。

## 性能与交互

- 审计分页从两次正向扫描改为一次逆向扫描，只保留当前页；256 项文件/筛选计数缓存使稳定的旧文件不再随每次翻页或统计重复解析，按大小和修改时间失效。缓存只改善展示统计，完整性校验不使用它。
- UI 监控独立探测最多三个并发，CPU/网络保留采样顺序，网络速率使用实际采样间隔；单项探测故障保留已经得到的字段。
- 终端增加离线搜索回看，`Ctrl+Shift+F` 打开，Enter / Shift+Enter 查找下一个 / 上一个，Esc 返回终端。只搜索当前标签现有回看缓存，不拉取远端日志。新增 xterm search addon 约 12 KiB，未引入 npm 构建步骤。
- 畸形或超额 `output_ack` 忽略且不增加信用，不再终止终端；畸形 resize 控制帧不进入 shell。终端票据与正在建立/已建立连接有合并上限，UI 会话表有上限。
- 历史和审计补充紧贴的 `-psecret`、`-p'with space'` 启发式脱敏，可能一并隐藏非秘密的 `-p` 参数；不承诺识别任意凭据格式。
