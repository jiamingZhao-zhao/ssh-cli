# 0.7.15：工作台体验与稳定性

本版复用已有 Go、Alpine CSP、Tabler 和 xterm，不新增运行时依赖、前端构建工具、字体或图标资源。版本号仍由发布构建注入，源码默认 `dev`。

## 交互

- 概况刷新等待上一轮完成再计时，失败后逐步退避到 30 秒；切换主机、离开工作台或隐藏页面会取消读取。探测使用独立 SSH channel，取消探测不会关闭共用的终端连接。
- 主机详情按请求顺序校验，旧响应不会覆盖新主机。切换主机时保留各自文件目录与目录树，最多记忆最近 16 台，仅在当前页面内有效，重新打开页面后不保留。
- 终端显示连接中、已连接、已断开或已到期；断线后可手动重连，不重放键盘输入。重复点击打开时只发起一次连接。终端尺寸随面板变化调整。
- 小屏切换终端、概况和文件面板，避免左栏挤占终端宽度。弹窗支持初始焦点、Tab 循环、Esc 关闭和关闭后返回焦点；原生确认框统一为页面弹窗。
- 批量执行先显示主机、环境、实际地址、模式和允许状态，再确认执行。请求发送中禁止重复提交；回复丢失时显示结果未知并提供查询入口。
- 审计页默认显示 CLI 与 UI 两种来源，保留来源筛选。

## 上传与安全

- 上传检查整个目标计划、实际目的路径及受保护路径的符号链接别名，拒绝通过目标或父目录符号链接写入；`/` 保护覆盖其全部子路径。
- 写入随机名称的同目录临时文件，在发送内容前限制为 0600，成功关闭且再次通过策略检查后替换目标。支持 OpenSSH POSIX rename 扩展时原子覆盖；不支持安全覆盖的服务端会报错并保留原文件。目录上传仍逐文件提交，不提供整棵目录事务。
- 网页覆盖已有文件需要单独确认；上传进度明确区分发送到本机和写入远端。取消请求会关闭上传专用连接，打断握手、SFTP 启动或写入。网络中断时远端临时文件的清理为尽力而为，可能需要手动清理 `.ssh-cli-upload-*`。远端同权限进程并发修改路径仍需依靠服务端权限隔离。
- 网页单文件上传上限 63 MiB，为 64 MiB 请求限制预留 multipart 开销；下载最多缓冲 128 MiB，超过时中止，较大文件使用 CLI。此限制针对网页，不影响命令行。
- `ss -MK`、`ss -MD` 和 `--kill` / `--diag` 缩写不能绕过 readonly / standard。`noDataOutflow` 拒绝无限制终端、概况和进程详情，保留受策略检查且默认丢弃输出的 exec 路径。
- 直接 SSH 握手立即响应上下文取消。

## 轻量执行预检与去重 API

沿用当前 UI session、CSRF、Bearer 和执行策略；预检不是授权令牌，也不能代替人工确认。提供给 AI 调用者的只是检查与去重能力，没有新增自动审批或后台任务平台。

1. `POST /api/exec/preview`：与 exec / batch 使用相同字段；返回 `hosts`、`canExecute`、`planDigest`。不连接主机，也不执行命令。
2. `POST /api/exec` 或 `/api/exec/batch`：可带预检返回的 `planDigest` 和随机 `operationId`（16–80 个字母、数字、`_`、`-`）。预检后目标、策略或请求改变会拒绝；执行仍走现有检查。409 确认响应尚未执行，可以补充确认内容后使用同一编号重提。
3. 已接收的同编号、同内容请求正在执行时返回 202，完成后返回缓存结果；同编号不同内容返回 409。`GET /api/operations/{id}` 只允许原 UI 会话查询，返回 `running`、`complete` 或 `unknown`。

记录仅在当前进程内保留，最多 32 条，完成记录从接收起保留 30 分钟；满时拒绝新任务。带操作编号的执行每台主机每个输出流最多保留 64 KiB，并返回 `truncated`。重启、过期、更换浏览器会话或网络中断可能使结果未知；这不是跨重启的“恰好一次”保证。调用者应保存编号并核验远端状态，不能把 404、超时或未知结果作为自动重放写操作的理由。原有不带这两个可选字段的 API 保持兼容。

## 验证

贡献者使用 `go test ./...`、`go vet ./...` 和 `node --test scripts/ui.test.cjs`。Node 仅用于测试，不随安装包分发。新增回归覆盖慢刷新、详情响应乱序、重复提交、断线状态、目录记忆、预检变更、去重与会话隔离、禁止数据带回、探测取消、握手取消，以及上传取消、覆盖和符号链接保护。
