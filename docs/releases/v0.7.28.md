# 0.7.28：多 Agent 一链接安装与中英文项目首页

本次只改文档和 Skill 安装脚本。不改 Go 代码、运行时依赖或内嵌网页资源；发布版本仍由标签经 ldflags 注入，源码里的 `Version` 保持 `dev`。

## 项目首页

- [README.md](../../README.md) 为默认中文首页，[README.en.md](../../README.en.md) 为对应英文介绍。首页按使用场景、安装 CLI、登记主机和打开工作台来组织，并保留语言切换。
- 首页给出仓库链接 `https://github.com/jiamingZhao-zhao/ssh-cli`。具备读取仓库和执行命令能力的 Agent 可按安装入口完成 Skill 安装；只浏览或审查仓库时不触发安装。

## 一链接安装

- [SETUP.md](../../SETUP.md) 与 [SETUP.en.md](../../SETUP.en.md) 规定安装顺序：识别当前客户端和执行环境，阅读来源后再执行，安装 Skill，缺失时再安装 CLI，核对文件与版本后报告结果。
- 支持的客户端名称为 `claude`、`codex`、`cursor`、`copilot`、`opencode`。无法确定客户端或没有执行工具时，应说明缺少什么，不声称已经安装。
- 安装报告区分 Skill 文件、客户端是否已发现、CLI 是否可用和主机清单是否读到。安装流程不连接服务器，不添加主机，也不测试写操作。

## Skill 安装脚本与指南

- [scripts/install-skill.sh](../../scripts/install-skill.sh) 与 [scripts/install-skill.ps1](../../scripts/install-skill.ps1) 只复制仓库根目录的 `SKILL.md` 到当前客户端的个人目录；指定已有项目目录时安装到该项目。不安装 CLI，不修改 Agent 设置，不复制凭据或 SSH 配置。
- 目标已是符号链接时拒绝替换。内容相同则成功跳过；内容不同则拒绝覆盖，需要显式 `--force` / `-Force` 才更新。
- [docs/skills.md](../skills.md) 与 [docs/skills.en.md](../skills.en.md) 列出各客户端的个人目录、项目目录和调用方式。详细用法仍见 [docs/usage.md](../usage.md)。
- `SKILL.md` 仍是同一份说明：要求显式 `-H`、尊重策略和人工确认，并保留 `agentKey` 与运行环境前置条件。0.7.26 的完整性、破窗、复用边界和 0.7.27 的 agent 身份行为没有变化。

## 验证

合并前在隔离环境核对了上述五个 Agent 目录，覆盖 PowerShell 5.1、PowerShell 7 和 Git sh：UTF-8 与带空格路径、相同内容重复安装、保留不同旧内容，以及显式更新。没有连接真实服务器，也没有宣称全部客户端都完成了真实 SSH 联调。
