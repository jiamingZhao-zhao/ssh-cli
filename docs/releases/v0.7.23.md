# v0.7.23 终端交互打磨

此版本说明随候选 PR 提交；版本号仍由发布标签注入，源码保持 `dev`。没有新增运行时依赖、前端组件包或构建步骤。

## 连接与错误

- 浏览器通道建立后仍显示「连接中」。SSH 连接和远端 PTY 启动完成后，服务端发送就绪消息，才显示已连接并允许输入。
- 连接失败区分认证、连接、超时和远端终端启动失败；错误保存在各自标签中，其他标签的输出不能清除它。
- 连接凭据请求尚未返回时关闭标签，不会在后台创建迟到的浏览器连接。旧连接的回调不能改变重连后的状态。
- 页面按钮明确为「打开终端」「连接文件」「断开此主机」。连接文件作用于当前工作区；断开此主机会关闭该主机的文件连接和全部终端，按钮提示说明范围。

## 多标签与重连

- 同主机标签有独立序号；长名称可查看完整标题，当前标签滚动到可见位置。
- 关闭当前标签切换至相邻标签。标签支持左右方向键、Home / End 和键盘焦点导航。
- 重连复用当前标签及其终端缓冲区，保留滚动输出并插入分隔提示；重新连接创建新的 shell，不恢复远端进程或自动执行旧命令。
- 若断线时处于 vim / top 等全屏画面，将最后可见画面保存为纯文本，再退出全屏模式并软重置终端模式。不会清空已有滚动输出；显示仍受现有 xterm 滚动缓冲容量限制。
- 断线清空尚未发送的输入；如果还有待发送数据，会提示部分内容可能已经到达远端，需要核验。重连不会重放这些输入。

## 输入、复制与显示

- 输入先按 UTF-8 编码，再分为不超过 32 KiB 的消息，保持发送顺序，避免一次大粘贴超过后端现有的 1 MiB 消息限制。
- 根据浏览器发送缓冲情况分批发送；待发送内容与浏览器缓冲合计限制为 4 MiB。超过限制的本次输入整段拒绝，不发送半条命令，并提示使用文件上传。
- 「复制选中」与 Ctrl+Shift+C 复制所选终端文字；Ctrl+C 继续发送中断字符。粘贴沿用 xterm 的输入法、换行和括号粘贴处理，不额外添加回车。
- 终端字号可在 12–22 px 间调整并记忆；文件区可一键收起、恢复并记忆，原有三分之一默认高度和拖动尺寸保留。
- 按终端区域实际宽度自动换行连接按钮，避免标签和「文件 / 历史」挤成窄条；长连接信息有完整标题提示。
- 修复隐藏字符测量元素影响手机页面布局宽度的问题。手机继续使用原有终端／概况／文件面板切换。

## 验证与边界

- 前端回归覆盖连接就绪、错误隔离、关闭期间迟到响应、重连旧消息、输入分块与上限、断线清理、相邻标签、键盘导航、复制、字号和布局偏好。
- Go 测试校验 PTY 真正启动后才发送就绪消息，失败响应带分类，保留原有终端策略、浏览器会话、票据、审计及空闲／最长时限测试。
- 原生 Windows CI 增加终端连接失败响应与标签结构检查；Linux 保留全量测试、OpenSSH 集成、安全扫描和六平台构建打包。
- 浏览器验证使用真实 Alpine / xterm 组件和模拟连接：1.4 MB 中文粘贴分成 43 段且逐字节一致；组合输入事件只发送一次中文；复制不发送命令，Ctrl+C 仍发送中断字符；重连保留输出及全屏快照并重置输入模式；检查桌面、中等宽度和 390 px 手机布局。
- 本机浏览器日志压力验证：约 6.7 MB 突发输出约 152 ms 排空；持续 5 秒输入约 26 MB 后，剩余队列约 4.5 ms 排空。该模拟负载下未见持续积压，因此本次保留现有输出通道，不增加流控协议。结果受机器与负载影响，不代表所有服务器和浏览器的性能。

终端文字只留在现有浏览器缓冲区；刷新页面仍不会恢复交互 shell。没有记录终端按键，也没有放宽只读环境、人工确认或浏览器会话限制。
